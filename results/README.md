# Results inputs

The final paper-figure script expects the following architecture-search and sensitivity CSV files in the repository root:

- `architecture_seed_results.csv`
- `combined_sensitivity.csv`
- `weight_sensitivity.csv`

It also uses the held-out arrays generated by the training and INT8 validation scripts under `outputs/`.

The CSV files are not generated by the scripts currently included in this repository and must be added separately to reproduce Figures 2, 5, and 6 exactly.
